# 🚀 AdPreview — Realistic Billboard & Ad Visualization

> **Put your ad anywhere. See it. Love it. Use it.**

AdPreview lets brands, agencies, and designers preview their advertisements on realistic billboard surfaces in under 60 seconds — with interactive corner stretching, 3D perspective depth, and custom typography overlays.

---

## ✨ Features

- **🌆 Photorealistic Billboard Library**: Highway billboards, downtown city towers, urban streets, transit hubs, and retail displays.
- **🔲 Freeform 8-Handle Corner Stretch**: Freely stretch, scale, and adjust aspect ratios to fit any billboard angle.
- **📐 3D Perspective & Tilt**: Dial in horizontal/vertical skew, rotation, and Z-axis depth for natural perspective matching.
- **✍️ Titles & Typography Overlays**: Add customizable headlines, subtitles, and CTA badges directly onto your canvas.
- **⚡ Sign-Up First Onboarding**: Frictionless passwordless email verification (OTP) with instant session restore.
- **📥 High-Resolution Exports**: Download crystal-clear composite images ready for client presentations, pitches, and ad campaigns.
- **📁 My Projects Cloud Dashboard**: Save, reload, and organize your mockup designs anytime.

---

## 🚀 Quick Start

### 1. Install & Run
```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### 2. Build for Production
```bash
npm run build
```

---

## 🛠️ Stack

- **Frontend**: React 18, Vite, TypeScript, Tailwind CSS
- **Interactive Canvas**: Konva.js / React-Konva
- **Icons & UI**: Lucide Icons, Radix UI Primitives
- **Backend & Auth**: Supabase, Stripe
